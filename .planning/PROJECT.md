# Project: RepoLens

## Overview
**RepoLens** is a modern Next.js-based repository analysis, visualization, and intelligence application designed to provide deep architectural insights, code inspection, and developer tooling.

## Tech Stack
- **Framework:** Next.js 16 (App Router), React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Linting:** ESLint 9

## Objectives & Vision
- Provide intuitive repository overview and inspection tools.
- Enable rich, interactive code and dependency visualization.
- Deliver an aesthetic, high-performance developer experience.

## Codebase State
- Initialized from Next.js starter with App Router, TypeScript, and Tailwind CSS.
- Codebase mapped in `.planning/codebase/`.
